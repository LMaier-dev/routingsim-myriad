# One eval run per line, executed from the repo's src/ directory.
# Blank lines and #-comments are ignored. run_evals.sh gives each line its own
# tmux window, so a run that hangs doesn't hold up the rest.
#
# --tag <name> suffixes the output dir; use it when two runs share a topology
# and scenario (e.g. basis=min vs tree) so they don't overwrite each other.
#
# Prefix a dynamics line with `SPLIT ` to run its PV and LS halves as parallel
# processes, then auto-combine the plots (--post). Same window, ~2x faster, and
# the flags stay written once. Example:
#   SPLIT python3 ~/routingsim/simulations/MYRIAD/eval_entrypoint.py dynamics --topo ~/routingsim/simulations/topologies/grid_10,10.txt --only churn --basis tree
#
# --topo <dir>@first|median|last picks one *.txt from a swept family dir, sorted
# by _tr<N> (min/mid/max transition count), so a run names a representative
# without pinning a tr/fan/seed filename that regeneration renames.

# Memory and hotspotting vs fan-out, at FIXED n=1000 (ringpipe --sweep-share
# with --hold-len, so ring length is pinned and only fan moves).
#
# Volume (messages + bytes) and LINK LOAD, both with and without RR. No state

# ---------------------------------------------------------------------------
# Per-router RIB state vs NODE COUNT (generate_topos.sh grow; ringgrow
# --sweep-n, A=300 tr=750 fixed), alongside volume with and without RR.
# --no-link-panel: per-link load is a function of FAN, and the ring graph is
# pinned here. No --norr: n runs to 8000, so the RR-excluded series comes from
# the free in-run subtraction instead of a third simulation per point.
#
# --jobs 2, NOT 6: LS holds an LSDB row per origin at every node, so its memory
# goes with n^2 -- 44GB measured at n=10000 scales to ~28GB at the n=8000 points
# here. measure() runs ls then pv sequentially so a job peaks at max(), but 6 of
# those is ~168GB on a box with ~78GB free. Run this one on its own.

# All three panels on the ringgrow corpus the dynamics runs use: state, volume
# and link load, each with and without RR. tr is the swept knob, so fan moves
# (link load means something) and n is fixed at 2500 (state is comparable).
